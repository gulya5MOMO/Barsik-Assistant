Barsik-Assistant
ИИ-ассистент в виде чёрного кота для Windows. Живёт на рабочем столе, управляет ПК по текстовым командам.

Установка
1. Скачай архив из раздела Releases.

В релизе лежат несколько частей архива — скачай их ВСЕ (обычно 3 файла). Без любой из частей архив не распакуется.

Файлы называются так:

AI-Cat.part1.rar

AI-Cat.part2.rar

AI-Cat.part3.rar

2. Создай пустую папку где угодно (например на рабочем столе) — назови Barsik.

3. Перекинь все скачанные части в эту папку. Должно получиться так:
text
Barsik\
├── AI-Cat.part1.rar
├── AI-Cat.part2.rar
└── AI-Cat.part3.rar
4. Если нет WinRAR — скачай тут: https://www.win-rar.com/download.html

5. Выдели ВСЕ части (Ctrl+A), наведи курсор на любую из них, нажми правую кнопку мыши → WinRAR → «Извлечь в текущую папку».

Распаковка займёт 3-5 минут.

6. После распаковки появится папка AI-Cat. Зайди в неё, потом в BarsikApp. Там найди файл Barsik.exe и запусти двойным кликом.

Первый запуск
Первый запуск может быть долгим — от 20 секунд до минуты. Модель загружается в память.

Первый ответ кота тоже может быть долгим — 10-30 секунд.

После этого всё работает стабильно — ответы занимают 2-5 секунд.

Управление
Кот перетаскивается мышью за тело. Команды вводятся в поле над котом.

Настройки — в трее (правый клик по иконке кота):

Показать / Спрятать

Голос: ВКЛ / ВЫКЛ

Рот: ВКЛ / ВЫКЛ

Выход — полностью выйти, не спрятать

⚠️ Важно
Не распаковывай части по отдельности. Все файлы должны лежать рядом, и ты выделяешь все сразу — WinRAR сам склеит их в один архив при распаковке.

Возможны некоторые недочёты. Разработчик старается как можно быстрее находить и исправлять их.
