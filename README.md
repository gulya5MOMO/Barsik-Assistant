Barsik-Assistant
ИИ-ассистент в виде чёрного кота для Windows. Живёт на вашем пк, и  управляет ПК по вашим  командам.

1.Запуск
Скачать архив из релизов, распаковать, зайти в BarsikApp, запустить Barsik.exe.
------------------------------------------------------------------------------
2.Управление
Кот перетаскивается мышью за тело. Команды вводятся в поле над котом.
--------------------------------------------------------------------
Настройки — в трее (правый клик по иконке кота):

Показать / Спрятать

Голос: ВКЛ / ВЫКЛ

Рот: ВКЛ / ВЫКЛ

Выход — полностью выйти, не спрятать

Возможны некоторые недочёты. Разработчик старается как можно быстрее находить и исправлять их.
